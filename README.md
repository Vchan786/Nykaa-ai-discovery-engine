# Nykaa Fashion AI Discovery Engine

## Product Management Graduation Project

This prototype demonstrates an AI-assisted discovery workflow
for identifying user problems that may influence wishlist-to-
purchase conversion.

## Workflow

Feedback
→ Intent
→ Purchase Blocker
→ Uncertainty
→ Behaviour
→ User Segment
→ Opportunity Area
→ Research Questions

## Important Note

This is a graduation-project prototype using illustrative/
public-style feedback. It does not use Nykaa Fashion internal
customer data.
